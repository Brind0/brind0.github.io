§ 01

Artefacts

oscola⁠-cite

An OSCOLA citation linter

Status: tested, ready to use.

Checks legal citation form against OSCOLA in an existing draft: fifteen rules across cases, legislation, books and journal articles. Standard-library only, no dependencies.

The receipt On its first live run against real seminar notes it caught a genuine defect, a case cited with no report and no court (McPhail v Doulton [1971]), the kind of error every existing OSCOLA tool generates citations rather than checks for.

github.com/Brind0/oscola-cite

sg⁠-statutes⁠-agent

Grounded retrieval over Singapore statutes

Status: in progress, one of four target Acts indexed.

Answers questions about Singapore legislation with pinpoint citations (Act, section, official deep link) and refuses to answer when it isn't grounded, rather than guessing. FTS5 and keyword ranking, no embeddings, no vector database.

The receipt Published eval, failures included: 50% recall@1 against a hand-built question set, and 50% refusal precision where a plain keyword baseline scored 33%. Recall dropped as more statutes were indexed and the question set hasn't caught up yet, the eval says so plainly rather than hiding it. Compliance with the source's terms of use (fetch windows, honest user agent, attribution) was designed in from the first commit, not bolted on after.

github.com/Brind0/sg-statutes-agent

life⁠-hub

A personal agentic operating system

Status: tests passing, private, unpublished.

The system that actually runs my life: study, finances, health, career, all agent-managed. SQLite underneath, strict per-agent write ownership so no two agents touch the same table, and a hard rule that AI never moves money: it proposes, I execute.

The receipt 48 tables, 800+ automated runs, 339 tests. Every write is deterministic and attributable; nothing autonomous touches a financial account.
